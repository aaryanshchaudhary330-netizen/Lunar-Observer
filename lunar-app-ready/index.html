MODULE // BOTTLENECKS SYSTEM CONSTRAINTS

Technical Bottlenecks & Mitigations

Ultra-Low Signal-to-Noise Ratio

CHALLENGE

PSRs are lit only by weak, secondary sunlight reflected off nearby crater rims. OHRC images suffer from extreme Poisson shot noise and Gaussian sensor read noise.

Iobs = P(Itrue) + N(0, σread2)
MITIGATION

Apply variance-stabilizing transformations (such as the Anscombe Transform) to convert signal-dependent Poisson noise into additive Gaussian noise before applying deep-learning denoising networks (e.g., NAFNet or Restormer).

False-Detail / Hallucination Risk

CHALLENGE

Standard generative models (like GANs or unfiltered Diffusion models) often invent non-existent rocks, craters, or surface textures when hallucinating fine details.

Ltotal = λ1LL1 + λ2(1-SSIM) + λ3LGrad
MITIGATION

Train networks using a strict Physics-Informed Loss Function that penalizes spatial distortion and preserves structural fidelity. Ensure edge gradients (boulder rims, ejecta blankets) match physical solar reflection bounds.

Dynamic Range & Contrast

CHALLENGE

Extremely narrow dynamic range causes histogram compression near zero values.

I = R ⊙ L
MITIGATION

Implement adaptive Retinex theory. Contrast Limited Adaptive Histogram Equalization (CLAHE) is applied exclusively to the illumination map L, preserving true surface reflectance R.

MODULE // VALIDATION DATA INTEGRITY

Scientific Validation Protocols

LROC Reference Imagery

Cross-verification against NASA's Lunar Reconnaissance Orbiter Camera datasets to ensure feature alignment.

LOLA Topography

Utilizing NASA's Lunar Orbiter Laser Altimeter for baseline topography and polar illumination reference.

Co-registration

Strict spatial alignment algorithms ensuring OHRC processed outputs geometrically match reference DEMs.

Shadow Geometry

Verifying that predicted shadows cast by crater rims match precise illumination angles.

Edge/Slope Consistency

Ensuring gradients and physical slopes are not exaggerated by contrast enhancement.

Residual-Noise Checks

Statistical analysis to ensure Poisson-Gaussian noise removal hasn't destroyed low-frequency data.
